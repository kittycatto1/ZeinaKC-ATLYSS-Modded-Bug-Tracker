# ZeinaKC's ATLYSS Modded Bug Tracker (UNOFFICIAL)
Since December 18th 2025 this repository was moved to [Modded-ATLYSS-Bug-Tracker](https://github.com/AtlyssModding/Modded-ATLYSS-Bug-Tracker) under AtlyssModding and on May 3rd 2026 it has been officially archived to reflect that. I have moved other resources this repository contained or intended to [ContentPacks-Spreadsheets](https://github.com/AtlyssModding/ContentPacks-Spreadsheets) and [ATLYSS-Modding-Resources](https://github.com/AtlyssModding/ATLYSS-Modding-Resources).

Go to the [Wiki page](https://github.com/kittycatto1/ZeinaKC-ATLYSS-Modded-Bug-Tracker/wiki/ATLYSS-Bug-Tracker) for the tracker itself. For vanilla bugs, use the [Steam Forums](https://steamcommunity.com/app/2768430/discussions/3/).\
Personally maintained bug tracker for modded ATLYSS with the goal of having easy access to troubleshooting information, keeping track of bugs, and miscellaneous things I put here for myself. Most of the reports are gathered through group contribution and efforts on my [Modpacks](https://thunderstore.io/c/atlyss/p/ZeinaKC/?section=bundles).

This isn't directly related to the mod authors (hence unofficial) and isn't the place to report bugs to get them resolved. Join the [Atlyss Modding Central Discord Server](https://discord.gg/hQceRJ7pEW) to get help with troubleshooting instead. Use the issues page to help report things to the tracker with [**troubleshooting standard**](https://github.com/kittycatto1/ZeinaKC-ATLYSS-Modded-Bug-Tracker/wiki/Troubleshooting-Standard).

Personal wishes: I'll be maintaining this for as long as my interest remains or until I get hit by a bus. Anyone is free to contribute to help make this a useful resource, though I wish for this repository to not have any duplicates until I am no longer actively maintaining it or available, where then anyone is free to continue on this project's goal.\
-Zeina (the) KC. Thank you, ATLYSS.
